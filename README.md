# 📈 M-Market — શેર બજાર ઇમ્પેક્ટ ન્યુઝ એપ

ભારતીય અને ગ્લોબલ ફાઇનાન્સ સમાચાર (English, हिंदी, Global) તથા દુનિયાના બજારોના આંકડા ભેગા કરી, આ એપ **આજનો અને આવતી કાલનો માર્કેટ મૂડ**, સેક્ટર પરની અસર અને કંપનીઓના સમાચાર ગુજરાતીમાં બતાવે છે.

> ⚠️ આ એપ ફક્ત જાણકારી માટે છે, રોકાણની સલાહ નથી. બજારની આગાહી ક્યારેય 100% સાચી હોતી નથી.

## 🚀 એક વખતનું સેટઅપ (આશરે 15 મિનિટ)

### સ્ટેપ 1 — GitHub પર રિપોઝિટરી બનાવો
1. github.com ખોલો → ઉપર જમણી બાજુ **+** → **New repository**
2. **Repository name:** `m-market`
3. **Public** પસંદ કરો ✅
   - Public રાખવાથી GitHub Actions અમર્યાદિત મફત ચાલે છે અને એપ પાસવર્ડ વગર ડેટા વાંચી શકે છે.
   - તમારી Gemini API key **Secrets** માં રહે છે, એટલે તે કોઈને દેખાતી નથી.
4. બીજું કંઈ ટિક કર્યા વગર **Create repository** દબાવો.

### સ્ટેપ 2 — ફાઇલો અપલોડ કરો
1. ZIP ફાઇલને કમ્પ્યુટરમાં **Extract** કરો (Right click → Extract All).
2. અંદરનું `m-market` ફોલ્ડર ખોલો. તેમાં `.github`, `app`, `collector`, `README.md` વગેરે દેખાશે.
3. GitHub પર નવી રિપોઝિટરીના પેજમાં **"uploading an existing file"** લિંક પર ક્લિક કરો.
4. `m-market` ફોલ્ડરની અંદરનું **બધું** (Ctrl + A) પસંદ કરી બ્રાઉઝરમાં drag & drop કરો.
   - ધ્યાન રાખો: `.github` ફોલ્ડર પણ સાથે જવું જ જોઈએ.
5. અપલોડ પૂરું થાય એટલે નીચે **Commit changes** દબાવો.
6. ✔️ ચેક કરો: રિપોઝિટરીમાં `.github/workflows` ફોલ્ડર દેખાય છે? ન દેખાય તો નીચે "મુશ્કેલી" વિભાગ જુઓ.

### સ્ટેપ 3 — Gemini AI key ઉમેરો (ભલામણ કરેલું, મફત)
1. **aistudio.google.com/apikey** ખોલો → Google એકાઉન્ટથી લૉગિન → **Create API key** → key કૉપી કરો.
2. GitHub રિપોઝિટરીમાં **Settings → Secrets and variables → Actions → New repository secret**
3. **Name:** `GEMINI_API_KEY`  **Secret:** કૉપી કરેલી key → **Add secret**

> key ન ઉમેરો તો પણ એપ ચાલશે. એ વખતે ગુજરાતી AI સારાંશ નહીં મળે, ફક્ત નિયમ આધારિત એનાલિસિસ મળશે.

### સ્ટેપ 4 — પહેલી વાર ડેટા ભેગો કરો
1. રિપોઝિટરીમાં ઉપર **Actions** ટેબ ખોલો. પૂછે તો **"I understand my workflows, go ahead and enable them"** દબાવો.
2. ડાબી બાજુ **Collect market data** → જમણી બાજુ **Run workflow** → લીલું **Run workflow** બટન દબાવો.
3. 2–4 મિનિટમાં લીલું ✅ દેખાશે. ત્યાર પછી આ કામ આપમેળે થતું રહેશે.

### સ્ટેપ 5 — APK ડાઉનલોડ કરી ફોનમાં ઇન્સ્ટોલ કરો
1. **Actions** માં **Build APK** પણ આપમેળે ચાલ્યું હશે (5–8 મિનિટ). ન ચાલ્યું હોય તો **Build APK → Run workflow** દબાવો.
2. લીલું ✅ થાય પછી રિપોઝિટરીના મુખ્ય પેજ પર જમણી બાજુ **Releases** પર ક્લિક કરો.
3. **ફોનમાં** આ પેજ ખોલી `M-Market-v1.0.x.apk` ડાઉનલોડ કરો.
4. ઇન્સ્ટોલ કરો. ફોન પૂછે તો **"Install unknown apps / અજાણી એપ ઇન્સ્ટોલ કરવાની મંજૂરી"** આપો.

🎉 બસ, એપ તૈયાર છે!

## ✏️ ફેરફાર કેવી રીતે કરવા?
- **નવી કંપની ઉમેરવી:** `collector/stocks.json`
- **નવી ન્યુઝ વેબસાઇટ (RSS) ઉમેરવી:** `collector/sources.json`
- GitHub પર ફાઇલ ખોલી ✏️ (Edit) દબાવી ફેરફાર કરો → **Commit changes**. એપ ફરી ઇન્સ્ટોલ કરવાની જરૂર નથી.

## 🛠️ મુશ્કેલી હોય તો
- **એપમાં "હજુ ડેટા તૈયાર નથી" દેખાય:** સ્ટેપ 4 ફરી કરો અને Actions માં લીલું ✅ આવ્યું છે તે ચેક કરો.
- **`.github` ફોલ્ડર અપલોડ ન થયું:** GitHub પર **Add file → Create new file** પસંદ કરો. નામમાં `.github/workflows/collect.yml` લખો, ZIP માંની એ જ ફાઇલનું લખાણ પેસ્ટ કરો અને **Commit** દબાવો. `build-apk.yml` માટે પણ આ જ રીતે કરો.
- **Actions લાલ ❌ બતાવે:** તેના પર ક્લિક કરી ભૂલનો સ્ક્રીનશૉટ Claude ને મોકલો.
- **AI ચાલતું નથી:** એપમાં ⚙ દબાવી "AI સ્થિતિ" જુઓ. key ખોટી હોય કે લિમિટ પૂરી થઈ હોય તો એપ આપમેળે નિયમ આધારિત એનાલિસિસ પર ચાલશે.
- **જાહેર રજાઓ:** NSE ની રજાના દિવસે પણ એપ "આગામી દિવસ" તરીકે એ તારીખ બતાવી શકે છે. આ મર્યાદા ધ્યાનમાં રાખજો.

## 📂 પ્રોજેક્ટની રચના
```
.github/workflows/collect.yml    ← ડેટા ભેગો કરવાનું શેડ્યૂલ
.github/workflows/build-apk.yml  ← APK બનાવવાનું
collector/collect.py             ← સમાચાર + માર્કેટ + એનાલિસિસ (Python)
collector/sources.json           ← ન્યુઝ ફીડ અને માર્કેટ સિમ્બોલ
collector/stocks.json            ← કંપનીઓ, સેક્ટર, હિન્દી/અંગ્રેજી નામ
app/                             ← એન્ડ્રોઇડ એપ (Kotlin + HTML UI)
```
ડેટા `data` નામની બ્રાન્ચમાં `latest.json` તરીકે સચવાય છે.
